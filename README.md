# victorkhen.github.io

Personal site of **Victor Khen**, technical go-to-market lead and product builder in open networking (Partner Marketing Manager at [IP Infusion](https://www.ipinfusion.com/)).

I run partner go-to-market and technical marketing for network software, and I built and operate [ipinfusion.com](https://www.ipinfusion.com/) and its OcNOS evaluation tools: the [Feature Matrix](https://www.ipinfusion.com/resources/ocnos-feature-matrix/), [Hardware Compatibility List](https://www.ipinfusion.com/resources/ocnos-hardware-compatibility-list/), [CLI Lab](https://www.ipinfusion.com/resources/ocnos-cli-lab/) and [AI Fabric Design Tool](https://www.ipinfusion.com/resources/ai-fabric-design-suite/). Nine merged pull requests bring OcNOS into netlab, containerlab, vrnetlab and the GNS3 registry.

Live: https://victorkhen.github.io/ · LinkedIn: https://www.linkedin.com/in/victorkhen/

## What is in this repo

| File | Purpose |
|---|---|
| `index.html` | Single-page profile. No build step, no external requests. Light and dark themes. |
| `fonts/` | Google Sans Flex (latin subset), self-hosted, SIL Open Font License (`fonts/OFL.txt`) |
| JSON-LD in `index.html` | `ProfilePage` + `Person` + `WebSite` + `ItemList` of work + `FAQPage`, linked by `@id` |
| `llms.txt` | Plain-text summary for AI assistants |
| `robots.txt`, `sitemap.xml` | Crawl policy (search and AI crawlers allowed) and sitemap |
| `og.png`, `favicon.svg`, `apple-touch-icon.png` | Share image and icons |
